
## Налаштування смартфону

Для контролю нахилів смартфона через дані акселерометра необхідно:
1) на смартфон встановити програму phyphox:
- https://phyphox.org/
- https://play.google.com/store/apps/details?id=de.rwth_aachen.phyphox&hl=en
2) обрати Raw Sensors:
- Acceleration with g
3) запустити HTTPS-сервер:
- натиснути кнопку ... (верхній правий куток екрану)
- вибрати "Allow remote access" 
- підтвердити включення серверу - кнопка OK (після система повідомить адресу сервера)
4) натиснути кнопку "Трикутник" (верхня панель), розповши отримання даних від акселеромента

## Налаштування Websocket-сервера

1) запустити програму
- python http2websocket.py
2) провести калібрування нейтрального розташування смартфтона 

## Особливості налаштування Websocket-клієнта

### Адаптація існуючих програм
Каталог містить приклади Scratch-програм (sb3-розширення), які клоновано з офіційного відкритого Scratch-репозиторія.
Для адаптації Scratch-програм під керування через нахили смартфону використано середовище TurboWarp:
1) Web - https://turbowarp.org/
2) Desktop - https://desktop.turbowarp.org/
Для обробки даних з Websocket-сервера у Scratch-програмах виконано наступні зміни:
- підключено WebSocket-розширення;
- створено Controller-спрайт, який встановлює значення змінної contr_direction (left, right, up, down)
- у відповідних спрайтах додано контроль нахилу через перевірку змінної contr_direction

Сервер передає дані accX,accY, враховуючи клаcичне вертикальне розташування смартфона.
Якщо смартфон розташувати горизонтально для зручного використання у більшості механоприладах,
тоді у програмах візуалізації необхідно змінити призначення: 
- для координат: x := accY, y := accX.
- для кутів нахілу: angle_x := angle_y, angle_y := angle_x

### Особливості адаптації
Програма може бути швидко адатована, якщо у програмі керування виконується через одноразове натискання клавіш клавіатури.
Якщо можливе довгострокове натискання клавіши, тоді виникає проблема дискретизації дії.
Наприклад, програма "3-Tetris-SmartPhone.sb3" використовує довгострокове натискання клавіш left, right для переміщення вліво/вправо.
Для припинення переміщення достатньо зняти натискання клавіши, але фізичне керування через нахили не дозволяє це зроби вчасно через фізичну затримку.
Тому запропоновано ввести ще один стан змінної contr_direction = null, який формується після завершення обробки сигналу натискання клавіши у відповідних спрайтах.
Controller-спрайт контролює цю зміну, не даючи можливість повторного спрацьовування події натискання та вимагаючи повернутися дол нейтрального положення смартфона.
Такий алгоритм забезпечує дискретизацію, яка в свою чергу гарантує вчасний контроль переміщення.
Але такий алгоритм адаптації не підходить для ігор, де алгоритм враховуює тривалість натискання клавіши, наприклад, у грі "7-Lightcube-Platformer-SmartPhone.sb3",
коли тривалість натискання призводить до збільшення висоти стрибку персонажа.

Також поки не запропоновано алгоритм адаптації для програми, які використовують "комп'ютерну мишу".

## Запуск програми

Програма `http2websocket.py` підтримує наступні параметри командного рядка для керування її поведінкою:

*   `--keys`: Активує режим емуляції натискань клавіш (W, S, A, D) на основі даних акселерометра. Для роботи цього режиму потрібна встановлена бібліотека `pydirectinput`.
*   `--osc`: Активує режим надсилання OSC (Open Sound Control) команд на основі даних акселерометра. Для роботи цього режиму потрібна встановлена бібліотека `python-osc`. OSC-команди надсилаються на `127.0.0.1:9000` за адресами `/input/MoveForward`, `/input/MoveBackward`, `/input/MoveLeft`, `/input/MoveRight` з булевим значенням `True` або `False`.
*   `--websocket`: Активує WebSocket сервер на `ws://localhost:8767`. Цей сервер транслює дані акселерометра підключеним клієнтам. Якщо цей параметр не вказано, WebSocket сервер не запускається.

**Приклади використання:**

*   Запуск лише з емуляцією клавіш:
    ```bash
    python http2websocket.py --keys
    ```
*   Запуск лише з надсиланням OSC команд:
    ```bash
    python http2websocket.py --osc
    ```
*   Запуск WebSocket серверу та емуляцією клавіш:
    ```bash
    python http2websocket.py --websocket --keys
    ```
*   Запуск з усіма режимами:
    ```bash
    python http2websocket.py --websocket --keys --osc
    ```

**Клавіші керування:**

*   `F1`: Калібрування стану спокою акселерометра.
*   `Esc`: Завершення роботи програми.

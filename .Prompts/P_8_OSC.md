# Context
1) OSC-протокол використовує функцію керування командами з однією булєвою змінною:
- вмикання команди - send_message("/input/command", True)
- вимикання команди - send_message("/input/command", False)

2) Приклад програмного коду:

from pythonosc import udp_client
import time

OSC_IP = "127.0.0.1"
OSC_PORT = 9000

client = udp_client.SimpleUDPClient(OSC_IP, OSC_PORT)

## команда руху вперед (клавіша w)
client.send_message("/input/MoveForward", True)
## команда руху назад (клавіша s)
client.send_message("/input/MoveBackward", True)
## команда руху наліво (клавіша a)
client.send_message("/input/MoveLeft", True)
## команда руху направо (клавіша d)
client.send_message("/input/MoveRight", True)

Саме такий тестовий об'єкт буде найбільш надійною основою для ваших подальших досліджень OSC у VRChat.


В одній VRChat грі знайшов декілька клавіш для керування ракеткою (предметом) в руці у трьох вісях:
1) вісь, горизонтальна екрану
- i - нахил вперед
- k - нахил назад
2) вісь, вертикальна екрану:
- j - поворот вліво
- l - поворот вправо
3) вісь, перпендикулярна екрану:
- u - поворот наліво проти часової стрілки
- o - поворот направо за часовою стрілкою

Клавіші	Дія
I / K	Змінюють pitch утримуваного предмета (обертання навколо осі X)
J / L	Змінюють yaw утримуваного предмета (обертання навколо осі Y)
U / O	Змінюють roll утримуваного предмета (обертання навколо осі Z)

https://docs.vrchat.com/docs/keyboard-and-mouse

Виявляється, для клавіш I, J, K, L, U, O існують прямі OSC-еквіваленти. VRChat надає спеціальні OSC-адреси для керування утримуваним предметом.

Дія	Клавіші Desktop	OSC-адреса	Тип
Переміщення предмета вперед/назад	Коліщатко миші	/input/MoveHoldFB	float (-1…1)
Обертання навколо осі Roll	U / O	/input/SpinHoldCwCcw	float (-1…1)
Обертання навколо осі Pitch	I / K	/input/SpinHoldUD	float (-1…1)
Обертання навколо осі Yaw	J / L	/input/SpinHoldLR	float (-1…1)

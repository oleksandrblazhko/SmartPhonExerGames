# Task
Розроби Python-програму, яка реалізує алгоритм:
“Algorithm for Minimal Combination Coverage of Games”
Задача:
На вході є набір ігор, кожна з яких описується списком ігрових механік.
Потрібно:
Знайти мінімальний набір комбінацій механік (subsets), які максимально покривають всі механіки у системі.
Мінімізувати кількість комбінацій при максимальному покритті.
Додатково оцінити якість покриття.
Алгоритм має підтримувати:
greedy heuristic (обов’язково)
optional brute-force для малих даних
оцінку coverage score

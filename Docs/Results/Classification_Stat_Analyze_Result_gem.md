# Статистичний аналіз результатів класифікації ігор

## 1. Запропоновані методи статистичного аналізу

Для аналізу категоріальних даних, отриманих у результаті класифікації, пропонуються наступні методи:

1.  **Описова статистика (Descriptive Statistics):** Розрахунок частот та відсоткових співвідношень для кожної категорії за кожним критерієм класифікації. Це дозволить побачити розподіл ігор.
2.  **Таблиці спряженості (Cross-tabulation) та критерій Хі-квадрат (Chi-squared test):** Для виявлення статистично значущих зв'язків між двома критеріями (наприклад, між "Ігровим сценарієм" та "Основною метою").
3.  **Кластерний аналіз (Cluster Analysis):** Для групування ігор у кластери на основі їх класифікаційних ознак. Це допоможе виявити групи схожих ігор.
4.  **Відповіднісний аналіз (Correspondence Analysis):** Для візуалізації зв'язків між категоріями різних критеріїв у багатовимірному просторі.

### 2.3. Кластерний аналіз (Концептуальний опис)

На основі отриманих даних можна було б провести кластерний аналіз, щоб згрупувати ігри. Очікувані кластери:
1.  **"Аркади на баланс (стоячи)"**: Найбільший кластер, що включає більшість ігор з BoBo Balance та частину ігор Wii Fit. Характеризуються динамічним балансуванням та механіками "Move" і "Avoid".
2.  **"Силові ігри в планці"**: Кластер, що повністю складається з ігор PlankPad. Характеризується положенням "Планка", фокусом на "Кор" і механіками, адаптованими під одновісний нахил.
3.  **"Багатофункціональні симуляції Wii Fit"**: Ігри з Wii Fit, що використовують додаткові контролери, імітаційні рухи та поєднують різні цілі (кардіо, сила, баланс).
4.  **"Головоломки та медитативні ігри"**: Невеликий кластер ігор, що вимагають статичного утримання або точного контролю (напр., Table Tilt, Lotus Focus).

**Висновки щодо ігрових механік:**

3.  **Роль "Random":** Випадковість появи перешкод чи бонусів використовується у третині ігор для підвищення реіграбельності та непередбачуваності.

    *   `Create` (створювати) є рідкісною механікою, поміченою у грі *Skateboard Arena* (виконання трюків).

### 3.1. Аналіз комбінацій ігрових механік (пари)

Багато ігор використовують не одну, а декілька механік одночасно для створення більш цікавого ігрового процесу. Аналіз парних комбінацій показує, які механіки найчастіше використовуються разом.

**Найпопулярніші комбінації з двох механік:**

| Комбінація механік | Кількість ігор | Частка від усіх ігор (48) |
| :--- | :---: | :---: |
| `Move` + `Avoid` | 18 | 37.5% |
| `Move` + `Random` | 14 | 29.2% |
| `Move` + `Match` | 13 | 27.1% |
| `Avoid` + `Random` | 13 | 27.1% |
| `Move` + `Manage` | 8 | 16.7% |
| `Avoid` + `Match` | 7 | 14.6% |
| `Match` + `Random`| 6 | 12.5% |
| `Avoid` + `Manage`| 6 | 12.5% |
| `Match` + `Manage`| 5 | 10.4% |

**Висновки щодо комбінацій:**

1.  **`Move` + `Avoid` (Рух + Ухилення):** Це абсолютний лідер. 37.5% всіх ігор використовують цю пару. Це фундаментальна комбінація для більшості аркадних ігор та симуляцій на балансувальній дошці: гравець керує рухом об'єкта (`Move`) і одночасно має уникати перешкод (`Avoid`).

2.  **`Move` + `Random` (Рух + Випадковість):** Друга за популярністю комбінація. Випадкова поява перешкод або бонусів робить ігровий процес `руху` менш передбачуваним і підвищує реіграбельність.

3.  **`Move` + `Match` (Рух + Збір/Співставлення):** Ця пара є ядром більшості аркад. Гравець `рухається`, щоб `зібрати` монети, фрукти, бонуси тощо. Це основний спосіб набору очок та досягнення мети гри.

4.  **`Avoid` + `Random` (Ухилення + Випадковість):** Ця комбінація підкреслює непередбачуваність ігор. Перешкоди, від яких потрібно `ухилятися`, з'являються `випадково`, що вимагає від гравця постійної концентрації та швидкої реакції.

### 3.2. Аналіз комбінацій ігрових механік (трійки)

Аналіз трійок дозволяє побачити більш складні ігрові патерни, що поєднують базову дію, виклик та елемент винагороди або непередбачуваності.

**Найпопулярніші комбінації з трьох механік:**

| Комбінація механік | Кількість ігор | Частка від усіх ігор (48) |
| :--- | :---: | :---: |
| `Move` + `Avoid` + `Random` | 10 | 20.8% |
| `Move` + `Match` + `Random` | 6 | 12.5% |
| `Move` + `Avoid` + `Match` | 5 | 10.4% |
| `Move` + `Avoid` + `Manage` | 4 | 8.3% |
| `Move` + `Match` + `Manage` | 4 | 8.3% |

**Висновки:**

1.  **`Move` + `Avoid` + `Random` (Рух + Ухилення + Випадковість):** Ця комбінація є найпоширенішою і зустрічається у 21% ігор. Вона створює класичний аркадний досвід: гравець рухається, ухиляючись від перешкод, що з'являються у випадковому порядку. Це ядро геймплею для таких ігор як *Balance Bubble*, *Color Tunnel*, *Fall Down*.

2.  **`Move` + `Match` + `Random` (Рух + Збір + Випадковість):** Друга за популярністю трійка. Гравець рухається, щоб збирати випадково розташовані предмети. Ця комбінація мотивує дослідження ігрового простору та швидку реакцію. Приклади: *Penguin Slide*, *Candy Rex*.

3.  **`Move` + `Avoid` + `Match` (Рух + Ухилення + Збір):** Ця комбінація створює динаміку "ризику та винагороди". Гравець повинен рухатись (`Move`), щоб збирати бонуси (`Match`), одночасно уникаючи зіткнень (`Avoid`). Ця трійка механік сама по собі *не включає* елемент випадковості (`Random`). Однак у деяких іграх, що містять ці три механіки, `Random` може бути присутнім як додаткова ігрова механіка (наприклад, у *BoBo Balance / Car* та *BoBo Balance / Submarine*). Це вимагає від гравця прийняття рішень та оцінки ризиків. Приклади ігор, які демонструють цю комбінацію без `Random`, включають *Wii Fit / Scuba Search* та *BoBo Balance / Harvest Rush*.

**Загальний висновок:**
Аналіз показує, що ринок Exergame-ігор для балансувальних дошок здебільшого стандартизований навколо простих та інтуїтивних механік (`Move`, `Avoid`, `Match`), що робить ігри доступними для широкої аудиторії. Системи відрізняються переважно за рахунок фізичного положення гравця (стоячи vs планка) та типу дошки, що впливає на динаміку керування. Wii Fit виділяється найбільшою різноманітністю ігрових сценаріїв та механік завдяки використанню додаткових контролерів.
